# Personal Job Intelligence System — Project Plan

## Phase 1: Foundation

- Create monorepo structure with web app, API, database package, and shared package.
- Provision PostgreSQL via Docker Compose.
- Define initial schema for user, skills, interests, career paths, sources, jobs, and job matches.
- Create backend endpoints for health, stats, jobs, sources, and profile.
- Build a minimal dashboard with navigation and empty states.
- Verify DB connectivity, migration, API behavior, and frontend rendering.

## Out of scope for this phase

- Job collection agents
- AI analysis and recommendations
- Telegram notifications
- Source discovery automation
- Advanced matching engine

## Delivery milestones

1. Project scaffold and environment configuration.
2. Database schema and migrations.
3. API layer with validation and pagination.
4. Dashboard + navigation + empty states.
5. Local verification and documentation.
